# goodbug89/homebrew-tap

Homebrew tap for [goodbug89](https://github.com/goodbug89)'s macOS utilities.

```bash
brew install --cask goodbug89/tap/hotkey-detective
```

`brew upgrade` keeps installed casks current.

| Cask | What it is |
|---|---|
| [`hotkey-detective`](https://github.com/goodbug89/hotkey-detective) | Menu-bar tool that identifies which app owns a keyboard shortcut |
